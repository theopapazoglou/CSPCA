# CSPCA: Covariance Supervised Principal Component Analysis

This file contains the code to perform Covariance Supervised Principal Component Analysis (CSPCA) and the scalable extension using Nyström's method for high dimensional settings. We also include the code to perform the simulation analysis and the two analyses on real-world genetic datasets. For regression, we use the Liver Toxicity Dataset from Alon et al. (1999) and for classification, we use the Leukemia Dataset by Golub et al. (1999). All analyses were performed using Python.
